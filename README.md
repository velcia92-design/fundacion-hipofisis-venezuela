# Fundación Hipófisis Venezuela

Proyecto de tesis de un estudiante de neurocirugía, pensado para crecer a toda Venezuela. Sede fundadora: Hospital Vargas. Página web sencilla (HTML + CSS, sin instalar nada).

- `index.html`: el contenido (los textos entre corchetes están por escribir).
- `style.css`: colores y diseño.

- `herramientas/`: material de estudio (uso educativo, no es opinión médica):
  - `atlas-encefalo.html`: atlas 3D del encéfalo por fases.
  - `plomada.html`: medición de parámetros espinopélvicos en una radiografía de perfil.
  - `guia-marcado.html`: guía paso a paso para marcar los puntos en Plomada.

Para verla: abrir `index.html` en el navegador.

Para publicarla en internet: en GitHub, Settings → Pages → «Deploy from a branch», elegir la rama y la carpeta `/ (root)`. La dirección queda como `https://velcia92-design.github.io/fundacion-hipofisis-venezuela/`.
